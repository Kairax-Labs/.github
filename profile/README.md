### 🧠 About Us
Born in Sri Lanka with a global vision, **Kairax Labs** is an AI-first technology startup. We don't just write code; we engineer intelligent ecosystems that adapt, learn, and solve complex problems autonomously. In a world of static applications, we are pioneering dynamic, AI-driven solutions.

### 🎯 Our Core Focus
- **Multi-Agent AI Systems:** Collaborative AI agents handling complex, multi-step workflows autonomously.
- **Custom ML Platforms:** Robust, scalable machine learning infrastructure tailored for enterprise needs.
- **Next-Gen Software Engineering:** Moving beyond traditional CRUD apps to create cognitive, self-optimizing tools.
